Privacy Policy

Last updated: July 15, 2026

This Privacy Policy explains what information Relay (the "Service") collects, how it is used, and the choices you have. Relay is a Discord application that lets members run AI chat and coding agents from within a Discord server. By using the Service you agree to this Policy.

Information we collect

  • Discord identifiers. When you sign in with Discord or use a command, we process your Discord user ID, the server (guild) ID, channel IDs, and your role IDs to enforce access control.
  • Server metadata. To power the setup dashboard, we read the server name, icon, roles, and channels via Discord's API.
  • AI provider API keys. Keys you add are encrypted before storage and are never displayed again or shared with server members.
  • Project configuration. Settings you create, such as the chosen provider, model, repository URL, allowed roles, and mapped channels.
  • Prompts and responses. The text you submit with a command and the response generated by your configured provider. These are transmitted to the AI provider you selected in order to fulfill the request.
  • Operational records. Limited run metadata (such as status, timestamps, agent/run identifiers, and rate-limit counters) used to operate the Service.

We do not intentionally collect special categories of personal data. Do not submit sensitive personal information in prompts.

How we use information

  • To authenticate you and enforce which roles and channels may use the bot;
  • To route your prompts to the AI provider you configured and return the results to Discord;
  • To operate, maintain, secure, and troubleshoot the Service, including rate limiting and preventing abuse.

We do not sell your personal data or use your prompts to train our own models.

Third-party services

The Service relies on the following processors:

  • Discord — the platform the bot runs on (Privacy Policy).
  • Cloudflare — hosting and request processing.
  • Supabase — database storage for configuration and encrypted credentials.
  • AI providers you connect — for example OpenAI, Google, Anthropic, OpenRouter, or Cursor. Prompts and related data are sent to the specific provider configured for a project, and are subject to that provider's privacy policy.

Data retention and deletion

  • Configuration and encrypted keys are retained while Relay is set up for your server.
  • You can remove an API key or delete a project at any time from the setup dashboard.
  • Removing Relay from your Discord server stops further processing; associated configuration can be deleted on request.

Security

API keys are encrypted at rest, and access to configuration is scoped to the authenticated administrator of each server. No method of transmission or storage is completely secure, and we cannot guarantee absolute security.

Children's privacy

The Service is not directed to individuals under the minimum age required to use Discord in their region, and we do not knowingly collect data from them.

Changes to this Policy

We may update this Policy from time to time. The "Last updated" date above reflects the latest revision. Continued use of the Service after changes take effect constitutes acceptance of the updated Policy.

Contact

Questions or data requests can be raised via the project's GitHub issues.
