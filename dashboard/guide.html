Setup Guide

Add Relay to your Discord server and let your team use AI with /agent — whatever they need it for. Setup is admin-only and one-time (about 5 minutes). Regular members don't set up anything — they just type /agent.

Mental model: Each Discord channel has exactly one Agent. /agent always uses that channel’s agent. Want a different AI? Use a different channel, or change the channel’s agent in the dashboard.
What this bot does: Chat (ChatGPT / Gemini / Claude), read-only codebase Q&A (OpenRouter + public GitHub repo), or coding agents (Cursor + optional PRs). Mix them by giving each its own channel.

What you'll need

  • Manage Server permission on your Discord server.
  • An API key for at least one AI provider (bring your own):
    • For chatting: OpenAI (ChatGPT), Google Gemini, or Anthropic (Claude) — no repo required.
    • For codebase Q&A: an OpenRouter API key plus a public https://github.com/owner/repo URL.
    • For coding agents: Cursor cloud agents — needs a Cursor API key and a GitHub repo connected to Cursor.

Step 1 — Add the bot to your server

  • On the dashboard, click Sign in with Discord and authorize.
  • Find your server and click Add to Discord. Relay prefills that server for you; approve the install to continue setup automatically.
  • Servers where Relay is already installed show Configure instead.

Step 2 — Connect Cursor to GitHub (coding only, once)

Only setting up chat (ChatGPT, Gemini, Claude) or OpenRouter codebase Q&A? Skip this step and go straight to Step 3. OpenRouter reads public GitHub APIs directly and does not use the Cursor GitHub App.

Cursor's cloud agent needs access to your repo to clone it and open PRs.

  • Go to cursor.com/dashboard → Integrations → GitHub.
  • Install/authorize the Cursor GitHub App on the account/org that owns your repo.
  • Grant access to the repo(s) you'll use (or "All repositories").

Step 3 — Connect an AI provider

Opening a server starts a guided setup with three steps: Connect AI, Create an agent, and Ready to use. On the first step, first choose what you're adding — Generic AI Chatbot or Coding Agent — then pick the specific AI, paste your key, click Save key (optionally Test connection → Connection OK), and Relay moves you to the next step automatically. Add a key for each AI you want to use.

Step 4 — Create an agent

An agent is one AI setup assigned to channels. Each channel can have only one agent. /agent always uses that channel’s agent.

FieldWhat to enter
Agent nameFriendly label members see in Discord
ProviderCursor, OpenRouter, ChatGPT, Gemini, or Claude
GitHub repo URL (Cursor / OpenRouter)https://github.com/owner/repo (public for OpenRouter)
Model (chat / OpenRouter)Suggested model or any model id
Channels (required)Pick channels, or click All channels
Allowed rolesAt least one role (not @everyone)
Auto-create pull requests (Cursor only)On if you want PRs
All channels means this agent answers everywhere. You can’t also assign other agents to specific channels. Prefer one agent per channel when you want different AIs in different places.
@everyone doesn't work as an allowed role. Create a real role (e.g. AI Access) and use that.

Step 5 — Use it

In a channel that has an agent:

/agent prompt: what are good ways to structure a REST API?

CommandWhat it does

/agent-new prompt:<text>Fresh run (same agent)

/agent-listAgents you can access

Want a different AI? Use a different channel (or change the channel’s agent in the dashboard).

Troubleshooting

MessageCause & fix
"This channel has no agent…"Assign an agent to that channel, or use All channels.
"You do not have an allowed role…"Add a real role (not @everyone) to the agent.
"Channel … is already assigned…"Each channel has one agent — edit the other agent first.
"No cursor API key is configured…"Add and save your Cursor key (Step 3).
Save says "Invalid agent"Check repo URL, channels (required), and role IDs.

Limits & notes

  • Limited new agents per user per hour; follow-ups are unlimited.
  • One active run per channel+agent at a time — or /agent-cancel.
  • Use /agent-new to force a fresh run in the same channel.
